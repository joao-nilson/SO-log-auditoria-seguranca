# SO-log-auditoria-seguranca
# Zeek Security Audit System

## Features
- Real-time network monitoring
- Historical log analysis
- Anomaly detection
- Automated reporting

## Installation
1. Install Zeek (https://zeek.org/)
2. `pip install -r requirements.txt`
3. Configure `config/settings.yaml`

## Usage
`python main.py --mode=realtime`  # For real-time monitoring
`python main.py --mode=analysis`  # For batch analysis
